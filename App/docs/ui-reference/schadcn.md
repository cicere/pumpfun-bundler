Usage Rule 
When using schadcn components.
- Use the schad-cn UI MCP server.

Planning Rule 
When planning to use anything related to schadcn:
- Use the schad-cn UI MCP server during planning
- Apply components wherever components are aplicable
- Use whole blocks where possible (e.g., login page, calendar,...etc)

Implementation Rule
When implementing: 
- First call the demo tool to see how it is used
- Then implement it so that it is implemented correctly
